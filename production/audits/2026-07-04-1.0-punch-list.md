## Phase 2.5 — Parts axis + inventory + rarity (2026-07-04, shape pending)

_Scope-in confirmed 2026-07-04. First-draft artifacts rolled back same day — mounted on wrong axis (combat SlotKind + chassis-agnostic sprites; corrected model is the per-vehicle decoration slot list Door/Bumper/Canister/Visor/Light, wired to `VehicleVisual._door/_bumper/_canister/_visor/_light`). Fresh TD consult against the corrected model is next; this section will re-grow with real P2.5.* items once TD returns._

**Confirmed model (from user 2026-07-04):**
- Per-vehicle decoration slot list — each chassis authors its own (PlayerVehicle: 5 slots today).
- Chassis-fresh = rough scrap (Common-tier default part per slot). Slots never empty.
- Rarities Common / Uncommon / Rare / Legendary.
- Sum of decoration parts = the armor pool (extends ADR-0012 sum-of-parts to the decoration axis).
- Top-right icon in Combat → fullscreen vehicle inventory UI (UI Toolkit per ADR-0014). Not persistent visible; press-to-open.
- Starting stat vocabulary parts can carry: dodge rate, crit rate, armor rating increase (playtest will expand).

**Open structural questions for TD:**
- Are decoration slot types per-chassis (Scout's Door only fits Scout) or shared categories (any "Bodywork" slot accepts any Bodywork part)? Locks drop-pool + inventory-fit rules.
- What full stat vocabulary does `PartDefinitionSO` need to carry to be data-forward through playtest? Dodge/crit/armor for M1; extension list.

**Phase 2.5 blocks (unchanged):**
- **P3.5γ Chopshop vertical** — cannot design install/swap without inventory + drops shape locked.
- **P3.4 reward pools SO** — must extend to cover a parts pool once shape lands.
